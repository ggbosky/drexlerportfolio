# Drexler – portfolio

Zdrojové soubory webu https://drexler-digital.vercel.app/ (čisté HTML/CSS/JS, bez build kroku).

- `index.html` – obsah stránky
- `styles.css`, `sekce.css`, `lightbox.css` – styly
- `main.js` – interakce (menu, galerie/lightbox, kontaktní formulář přes Web3Forms)
- `assets/img/` – obrázky

Lokální náhled: otevři `index.html` v prohlížeči, nebo spusť `python3 -m http.server` a jdi na http://localhost:8000.

## Karel Drexler st.

Samostatná stránka ve složce `starsi/` (na webu `/starsi/`) s vlastní identitou, nezávislou na stylech drexler.digital: `starsi/index.html`, `starsi/starsi.css`, `starsi/starsi.js`, `starsi/favicon.svg`.

- Fotka: stačí nahrát portrét jako `starsi/assets/img/karel-starsi.webp` (ideálně na výšku 4:5). Dokud tam není, profilová karta ukazuje monogram KD.
- Životopis vychází z veřejné části LinkedInu (SAZKA a.s. od 12/2023, Globus ČR 3/2019–12/2023); popisy pozic a dovednosti jsou odvozené z názvů rolí, je dobré je zkontrolovat.
